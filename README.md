# 🧬 GeneInsight

A Python-based DNA Sequence Analysis Toolkit for Bioinformatics.

---

## 📖 Overview

GeneInsight is a beginner-friendly bioinformatics project developed in Python. It performs fundamental DNA sequence analysis, including sequence validation, nucleotide counting, GC content calculation, reverse complement generation, transcription, translation, ORF detection, restriction enzyme site identification, FASTA file reading, and report generation.

---

## ✨ Features

- ✅ DNA Sequence Validation
- ✅ Nucleotide Counting
- ✅ GC Content Calculation
- ✅ Reverse Complement
- ✅ DNA → RNA Transcription
- ✅ RNA → Protein Translation
- ✅ ORF Detection
- ✅ FASTA File Reader
- ✅ Restriction Enzyme Site Finder
- ✅ Automatic Report Generation

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/roshnikathiresan-cloud/GeneInsight.git
```

Go to the project

```bash
cd GeneInsight
```

Create a virtual environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the project

```bash
python main.py
```
